# Mishnah Reader — Merge Guide

Technical instructions for merging the Mishnah Reader feature from this fork into the production ChavrutAI codebase.

---

## Overview

This feature adds a standalone Mishnah reader for **26 tractates** not covered by Talmud Bavli. It includes:
- Bilingual Hebrew-English chapter reader (mirrors the Bible reader layout)
- Tractate table of contents with chapter/mishnah navigation
- Main contents page organized by Seder with translator attribution
- Mishnah-Talmud mapping page
- Custom text processing (Hebrew and English)
- SEO metadata for all Mishnah routes
- Server-side API routes with in-memory caching

### `client/src/lib/text-processing.ts`
Add two new functions (these are additive, do not modify existing functions):

1. **`processMishnahHebrewText(text: string): string`** — Removes nikud, replaces `אומר,` → `אומר:` and `אומרים,` → `אומרים:`, normalizes whitespace.

2. **`processMishnahEnglishText(text: string): string`** — Strips HTML, applies name replacements (`R.` → `R'`, `Joshua` → `Yehoshua`, `Judah` → `Yehuda`, `Yose` → `Yosei`, `Ishmael` → `Yishmael`, `thy` → `your`, `thyself` → `yourself`, `said,` → `said:`), splits on sentence-ending punctuation (`.;:?!,`) with protections for `i.e.`, `e.g.`, `R'`, and `.]` sequences.

### `server/routes.ts`
Add these sections:

1. **SEO metadata** — Add `servePageWithMeta` handler cases for:
   - `/mishnah-map`
   - `/mishnah`
   - `/mishnah/:tractate/:chapter` (regex: `/^\/mishnah\/[^/]+\/\d+$/`)
   - `/mishnah/:tractate` (regex: `/^\/mishnah\/[^/]+$/`)

2. **Route registration** — Add `app.get('/mishnah-map', servePageWithMeta)` alongside other page routes.

3. **API endpoints** (3 new routes):
   - `GET /api/mishnah/tractates` — Returns `MISHNAH_ONLY_TRACTATES` array
   - `GET /api/mishnah/:tractate/info` — Returns chapter count and mishnayot-per-chapter (with in-memory cache `mishnahInfoCache`)
   - `GET /api/mishnah/:tractate/:chapter` — Fetches text from Sefaria API (`Mishnah_${sefariaName}.${chapter}`) and returns `{ hebrewSections, englishSections, sectionNames }`

4. **Imports** — Add to existing import from `@shared/tractates`:
   ```ts
   import { normalizeMishnahTractateName, isValidMishnahTractate, getMishnahTractateInfo, MISHNAH_ONLY_TRACTATES } from "@shared/tractates";
   ```

## API Dependencies

The Mishnah reader fetches text from the **Sefaria API**:
- Text endpoint: `https://www.sefaria.org/api/v3/texts/Mishnah_{tractate}.{chapter}?version=all`
- Info endpoint: `https://www.sefaria.org/api/v3/texts/Mishnah_{tractate}` (for chapter counts)

No API key needed — Sefaria's text API is public.

## URL Structure

| Route | Purpose |
|-------|---------|
| `/mishnah` | Main contents (all 26 tractates by Seder) |
| `/mishnah/:tractate` | Chapter TOC (e.g., `/mishnah/Peah`) |
| `/mishnah/:tractate/:chapter` | Chapter reader (e.g., `/mishnah/Peah/3`) |
| `/mishnah-map` | Mishnah-to-Talmud mapping |

Tractate slugs use proper case with underscores (e.g., `Maaser_Sheni`, `Bava_Kamma`).
Special case: display name "Uktzin" maps to Sefaria's `Mishnah_Oktzin`.

## Testing Checklist

After merge, verify:
1. `/mishnah` — Lists all 26 tractates grouped by Seder
2. `/mishnah/Peah` — Shows chapter TOC with mishnah buttons
3. `/mishnah/Peah/3` — Bilingual text, 50/50 columns, proper Hebrew/English
4. Hebrew text shows `אומר:` (colon, not comma)
5. English text shows `R'` (not `R.`), `Yehoshua` (not `Joshua`), `said:` (not `said,`)
6. Copy-paste from chapter page produces clean text (Hebrew first, no badges)
7. `/mishnah-map` — Mapping page loads correctly
8. Navigation: hamburger menu has Mishnah link, home page has Browse Mishnah button
9. Mobile: 50/50 columns maintained, text readable
10. SEO: check page titles/meta descriptions on all Mishnah routes
